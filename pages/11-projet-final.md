# 🎯 Module 11
## Projet final : Portfolio personnel

### Mettez en pratique tout ce que vous avez appris

---

# Le projet 📋

**Créez un portfolio personnel** avec :
- Header avec navigation
- Section Hero (présentation)
- Section Compétences (grille de cartes)
- Section Projets (galerie responsive)
- Section Contact (formulaire)
- Footer

---

# Contraintes techniques ⚙️

- HTML5 sémantique
- CSS externe (1 fichier)
- Flexbox ET Grid
- Responsive (Mobile First)
- Animations et transitions
- Google Fonts
- Pas de framework CSS (tout à la main !)

**Durée : 1h30**

---

# Structure HTML recommandée

```html
<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <meta name="viewport"
    content="width=device-width, initial-scale=1.0">
  <title>Mon Portfolio</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <header><!-- Nav --></header>
  <main>
    <section id="hero"><!-- Hero --></section>
    <section id="skills"><!-- Compétences --></section>
    <section id="projects"><!-- Projets --></section>
    <section id="contact"><!-- Contact --></section>
  </main>
  <footer><!-- Footer --></footer>
</body>
</html>
```

---

# Indications CSS

**Variables CSS (optionnel mais recommandé) :**

```css
:root {
  --primary: #2563eb;
  --dark: #1a1a2e;
  --light: #f5f5f5;
  --text: #333;
  --radius: 12px;
}
```

**Structure CSS recommandée :**
1. Reset/Base
2. Typographie
3. Header/Nav
4. Hero
5. Sections (Skills, Projects, Contact)
6. Footer
7. Responsive
8. Animations
