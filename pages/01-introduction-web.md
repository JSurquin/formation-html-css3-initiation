# 🌍 Module 1
## Introduction au Web

### Comment fonctionne Internet et le Web ?

---

# Comment fonctionne Internet ? 🌐

**Internet** = un réseau mondial d'ordinateurs interconnectés.

**Le Web** = un service qui fonctionne sur Internet (comme l'email).

**Analogie :**
- Internet = le réseau routier
- Le Web = les magasins accessibles via ces routes
- URL = l'adresse du magasin
- Navigateur = votre voiture

---

# Client / Serveur 🖥️

**Le modèle client-serveur :**

1. **Client** (navigateur) : envoie une requête
2. **Serveur** : reçoit, traite et renvoie la réponse
3. **Client** : affiche le résultat

**Protocole HTTP/HTTPS :**
- **HTTP** : HyperText Transfer Protocol
- **HTTPS** : HTTP + Sécurisé (chiffré)
- Le navigateur envoie des requêtes GET, POST, etc.

---

# Les 3 langages du Web 🏗️

| Langage | Rôle | Analogie |
|---------|------|----------|
| **HTML** | Structure | Le squelette de la maison |
| **CSS** | Présentation | La peinture et la décoration |
| **JavaScript** | Interaction | L'électricité et la plomberie |

Dans cette formation, nous nous concentrons sur **HTML** et **CSS**.

---

# Les navigateurs web 🧭

**Principaux navigateurs :**
- Google Chrome (65% de part de marché)
- Safari (18%)
- Firefox (3%)
- Edge (5%)

**Moteurs de rendu :**
- **Blink** : Chrome, Edge, Opera
- **WebKit** : Safari
- **Gecko** : Firefox

> Tous interprètent le HTML et CSS pour afficher les pages.

---

# Outils de développement 🛠️

**VSCode** (Visual Studio Code) : l'éditeur recommandé

**Extensions essentielles :**
- **Live Server** : prévisualisation en temps réel
- **Prettier** : formatage automatique du code
- **Auto Rename Tag** : renomme les balises par paire
- **HTML CSS Support** : autocomplétion

**DevTools du navigateur (F12) :**
- Inspecter les éléments HTML
- Modifier le CSS en direct
- Console JavaScript
- Onglet Network pour les requêtes

---

# Créer son premier fichier HTML 📄

1. Ouvrir VSCode
2. Créer un fichier `index.html`
3. Taper `!` puis `Tab` → génère le squelette HTML5
4. Clic droit → "Open with Live Server"

---

# En résumé 📝

- Internet est un **réseau**, le Web est un **service**
- Le modèle **client-serveur** : requête → réponse
- **HTML** = structure, **CSS** = style, **JS** = interaction
- **VSCode** est l'éditeur recommandé
- **Live Server** pour voir le résultat en temps réel
- **F12** pour les DevTools du navigateur
